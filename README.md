# UMBRAL Hybrid AI — Product Discovery

[Español](README.es.md)

> Discovery documentation only. This repository does not yet contain a production application or a submitted entry. References were checked on 12 November 2026 unless otherwise noted; competition rules and SDK behavior must be rechecked before submission.

UMBRAL Hybrid AI is a proposed opportunity companion that helps people find trustworthy opportunities, understand requirements, and plan next steps without becoming a generic chatbot. The recommended first release is a responsive web experience with a small curated, source-linked catalog, a local personal route, and contextual assistance through Firebase AI Logic. Device inference, cloud fallback, privacy and execution provenance require an actual feasibility test; a requested execution preference is not proof of where a model ran.
